🦇 luv-byte
X에서 마음을 누르면 지정한 이미지가 하트 위에서 튀어나오는 크롬 확장 프로그램입니다. 기본 이미지는 귀여운 박쥐지만, 설정 창에서 원하는 이미지로 바꿀 수 있어요.


1) 설치 방법
zip 압축을 푼 폴더를 컴퓨터에 저장합니다.
크롬 주소창에 chrome://extensions 를 입력하고 이동합니다.
오른쪽 위의 개발자 모드를 켭니다.
왼쪽 위 **'압축해제된 확장 프로그램을 로드'**버튼을 누릅니다.
저장해 둔 luv-byte 폴더를 선택합니다.
이미지를 올린 후 트위터를 새로고침해주세요.

💡 툴바에 아이콘이 안 보이면, 크롬 오른쪽 위 퍼즐 조각 모양(🧩)을 누른 뒤 luv-byte 옆의 압정(📌)을 클릭하면 툴바에 고정됩니다.


2) 파일 구성

manifest.json	확장 프로그램의 기본 정보와 권한 설정
content.js	트위터 화면에서 하트 클릭을 감지하고 이미지를 띄움
popup.html	설정 창의 화면
popup.js	설정 창의 동작 (이미지·크기·켜기끄기 저장)
images/pop.png	기본 박쥐 이미지
icon16/48/128.png	확장 프로그램 아이콘

3) 참고
이 확장 프로그램은 내 브라우저 화면에만 이미지를 보여줍니다. 트윗에 무언가 올라가거나, 다른 사람에게 보이거나, 트위터 서버에 데이터를 보내지 않습니다.
설정한 이미지와 값은 내 브라우저 안에만 저장됩니다.
트위터(X)의 화면 구조가 바뀌면 하트 감지가 동작하지 않을 수 있습니다.
